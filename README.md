# Product Pricing Assistant

## Overview

This project demonstrates the use of JavaScript variables, arithmetic operations, boolean expressions, math functions, and a nicely formatted console output.

## Features

- Calculates a discounted product price
- Applies sales tax to determine the final selling price
- Computes profit earned on each unit sold
- Calculates the number of units needed to break even
- Indicates whether the product generates a positive profit
- Displays results in the browser console

## Technologies Used

- JavaScript
